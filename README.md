# Lyric Library releases

Windows installers for **Lyric Library**, an offline lyric video library for vMix.

Download the latest `LyricLibrary-Setup-x.y.z.exe` from **Releases** and run it.
Installed copies find new versions here automatically when they're online
(About > Install update). For PCs without internet, copy the installer to a USB stick
and use About > Install update from file.

This repository only hosts the installers.
